カスケード、継承、優先順位、!important

カスケードとは、同じ要素へ複数の宣言が届いたときに、どれを採用するか決める仕組みです。「CSSが効かない」ときは、まずこの順序を確認します。

弱い候補
p { color: gray; }
→
より具体的
.note { color: teal; }
→
重要宣言
color: coral !important;
親：文字色と文字サイズを指定

子：colorとfont-sizeを継承

一方、marginやpaddingは通常、子へ継承されません。

セレクタの詳細度（教科書の高い順）
1インラインスタイル
2IDセレクタ
3クラス・属性セレクタ・疑似クラス
4タイプセレクタ・疑似要素
  1. まず重要宣言か：!importantの有無
  2. 次に適用元：教科書の優先関係を確認
  3. 次に詳細度：ID、class・属性・疑似クラス、要素などの具体性
  4. 同点なら後：同じ優先度なら、後に書かれた宣言

教科書基準：通常宣言はインライン → 外部・内部 → ユーザースタイル → ブラウザ既定の順で扱います。!importantを多用すると上書き関係が読みにくくなるため、必要な場面に限定します。

!importantを含む適用元の順序（教科書掲載順）
1ユーザースタイル（!important付き）
2外部・内部スタイル（!important付き）
3インラインスタイル
4外部・内部スタイル
5ユーザースタイル
6ユーザエージェント（ブラウザ既定）スタイル

@keyframes と animation

@keyframesは変化の節目を定義し、animation-nameで要素と結びます。0%と100%だけでなく、途中の場面も作れます。

☁
transition

通常はhoverなど、状態が変わるきっかけが必要。

animation

読み込み直後から再生でき、複数の節目や繰り返しを設定できる。

@keyframes cloud-trip {
  0%   { left: 4%; }
  50%  { left: 72%; }
  100% { left: 4%; }
}

.moving-cloud {
  animation-name: cloud-trip;
  animation-duration: 6s;
  animation-iteration-count: infinite;
  animation-direction: alternate;
}
教科書に掲載される主なanimation関連プロパティ
animation関連指定の短縮形
animation-name@keyframesの名前
animation-delay開始までの待ち時間
animation-duration1回の実行時間
animation-iteration-count繰り返し回数。infiniteは無限
animation-timing-function変化のタイミング。ease-in、ease-outなども使える
animation-directionnormal、reverse、alternateなどの実行方向
animation-play-staterunning（実行）またはpaused（停止）
animation-fill-mode実行前後のスタイル。forwards、backwards、bothなど

試験で見抜く：iteration-countは回数（infiniteは無限）、directionは再生方向です。alternateは奇数回を順方向、偶数回を逆方向にします。

directionは文字方向を示し、ltrは左から右、rtlは右から左です。unicode-bidi: bidi-overrideと組み合わせると、指定方向を強制できます。

ltr：CSS 123 ABC

rtl + bidi-override：CSS 123 ABC

quotes と生成する引用符
