# CSSを触って覚える — HTML5プロフェッショナル認定試験 Level.1 第2章

`index.html`をブラウザーで開くだけで学習できます。インターネット接続は不要です。

## おすすめの使い方

1. 上から順に説明と実例を読む
2. `css/style.css`で`TRY:`を検索して、指定値を1つ変更する
3. 各セクション末尾の練習問題へ進む
4. `css/style.css`の`PRACTICE 01`〜`07`へ自分のCSSを書く
5. ページ内で実際に動く完成例と比較する
6. 最後に`css/answer.css`で正解例とコメントを確認する

## ファイル構成

- `index.html` — 説明、デモ、7問の練習問題、HTML＋CSSで動く完成例
- `css/style.css` — 学習者が読む・編集するCSS。正解宣言は含みません
- `css/answer.css` — 練習問題7問の解答CSS
- `css/imported-theme.css` — `@import`で読み込む練習用CSS
- `assets/` — 教材用の動物・風景画像
- `fonts/` — LINE Seed JP（SIL Open Font License 1.1）
- `SOURCE-MAP.md` — 教科書・学習希望リスト・公式出題範囲との対応表

## 練習問題の注意

`index.html`は`css/answer.css`を読み込みますが、解答CSSは`.answer-live`内の完成例だけへ適用されます。上側の未完成問題には正解が適用されません。各問題では、対象タグ・クラス・記述するセレクタ・`style.css`の記入範囲を確認してからCSSを書いてください。

## 対象範囲

授業で使用する『HTML5教科書』第2章とHTML5プロフェッショナル認定試験 Level.1のCSS出題範囲に合わせています。新しいCSS機能の紹介を目的にしていません。`clip`など現在は新規制作で採用されにくい項目も、教科書・試験の学習対象として区別して掲載しています。
