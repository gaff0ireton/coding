flexbox 練習問題(上級編)

03_advanced/style.css を編集して、それぞれの目標を達成しましょう。 上級編は、1つのコンポーネントの中で flexboxを何重にも入れ子 にして 組み立てる練習です。編集する場所には /* TODO */ というコメントが書かれています。 また、一部の要素は便宜上 width で幅を指定していますが、 flexアイテムとして扱う場合は flex-basis に書き換えたほうが適切です。 該当箇所にも /* TODO */ コメントがあります。

問題1：料金プランを組み立てる（入れ子のflexbox）

目標：.advanced1_features の中に3枚のカードがあります。 以下を満たすように組み立ててください。

  • 3枚のカードを横に並べ、間隔を16pxにする。
  • 各カードは flex: 1; にして 幅を均等に分け合う ようにする （説明文の分量が違っても、カードの幅は同じになるようにする）。
  • 各 .advanced1_card の中身（見出し行・説明文・ボタン）を 縦に 並べ、間隔を16pxにする。 説明文の分量が違っても、ボタンは常にカードの一番下 に表示されるようにする。
  • .advanced1_card_head の中では、アイコンとタイトルを 横に並べて縦方向の中央 で揃える。間隔は16pxとする。

問題2：記事プレビューを組み立てる（入れ子のflexbox）

目標：.advanced2_media の中の画像と本文エリアを、 以下を満たすように組み立ててください。間隔はすべて16pxとする。

  • 画像を 左、.advanced2_media_body （タイトル・説明文・投稿者情報をまとめたエリア）を 右 に配置する。
  • 画像側は flex-basis を 200px にし、flex-shrink を 0 にして幅を固定し、縮まないようにする。
  • .advanced2_media_body 側は flex: 1; にして 残りの幅いっぱいに広げる。
  • .advanced2_media_body の中身を 縦に 並べる。
  • .advanced2_author の中では、アバター画像と名前・役職を 横に並べて縦方向の中央 で揃える。

flexboxで組み立てるレイアウト入門
