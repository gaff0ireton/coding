flexbox 練習問題(中級)

02_intermediate/style.css を編集して、それぞれの目標を達成しましょう。 中級編は、ヘッダーやカードなど 実際のUIパーツ を組み立てる練習です。 編集する場所には、 /* TODO */ というコメントが書かれています。 また、一部の要素は便宜上 width で幅を指定していますが、 flexアイテムとして扱う場合は flex-basis に書き換えたほうが適切です。 該当箇所にも /* TODO */ コメントがあります。

問題1：ヘッダーを組み立てる

目標：.problem1_header の中の要素を、以下を満たすように配置してください。

  • ロゴを 左端、.problem1_right （ナビゲーションとボタンをまとめたグループ）を 右端 に配置する。
  • 高さの異なる要素同士も 縦方向の中央 で揃える。
  • .problem1_right 自体も、中のナビゲーションとボタンが 横に並び、間隔が24pxあいて 縦方向の中央 で揃うようにする。
