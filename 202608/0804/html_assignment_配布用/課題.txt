====================================================================
課題：「日本の世界遺産」ページのコーディング
====================================================================

【概要】
このフォルダに用意された原稿（原稿.txt）と画像（images フォルダ）を使い、
「日本の世界遺産」を紹介する1ページのWebサイトを index.html に
セマンティックなHTMLでコーディングしてください。
CSSは使用しません（装飾は行わず、ブラウザ標準のスタイルのままでOKです）。

【配布ファイル】
・原稿.txt      … ページに掲載するテキスト原稿
・comp.webp     … 完成見本のスクリーンショット（レイアウトの参考にしてください）
・images フォルダ
    - about.webp         … 「世界遺産とは」セクションの画像
    - himejijyo.webp     … 姫路城の画像
    - shirakawagou.webp  … 白川郷の合掌造り集落の画像
    - itsukushima.webp   … 厳島神社の画像

※index.html   … このフォルダの直下に自身で作成してください

--------------------------------------------------------------------
【要件1】ページ全体の構成
--------------------------------------------------------------------
以下の3つのセクションを持つ1ページのサイトを作成してください。

  1. 世界遺産とは
  2. 登録遺産（姫路城／白川郷の合掌造り集落／厳島神社の3件）
  3. 世界遺産登録数の比較

ページ上部には、上記3セクションへ移動できるページ内リンク（アンカーリンク）
のナビゲーションを設置してください。

--------------------------------------------------------------------
【要件2】セマンティックマークアップ
--------------------------------------------------------------------
divタグに頼らず、内容に合った意味のあるHTMLタグを使ってコーディングして
ください。特に以下のタグを、適切な場所で使用することを意識してください。

  ・<header>   … ページ上部（タイトルとナビゲーション）
  ・<nav>      … ページ内リンクのナビゲーション部分
  ・<main>     … ページの主要コンテンツ全体
  ・<section>  … 意味のあるまとまりごと（3つの大セクション、および
              　 登録遺産内の各遺産の紹介ブロックにも使用）
  ・<footer>   … ページ下部（コピーライト表記）
  ・<h1>〜<h3> … 見出し。以下の見出しレベルを守ってください
       h1：ページ全体のタイトル（1つだけ）
       h2：3つの大セクションの見出し
       h3：登録遺産セクション内、各遺産の名前
  ・<ul><li>   … ナビゲーションのリンク一覧
  ・<img>      … 画像。alt属性に画像の内容を説明する文言を必ず入れる
  ・<a>        … リンク（ページ内リンク／UNESCO外部サイトへのリンク）
  ・<table>    … 「登録数の比較」の表。<thead><tbody><tr><th><td>を
              　 適切に使い分けること（見出しセルは<th>、データセルは<td>）

--------------------------------------------------------------------
【要件3】id名の指定（重要）
--------------------------------------------------------------------
ページ上部のナビゲーションから各セクションへリンクできるように、
3つの大セクションには以下のid名を必ずそのまま指定してください。

  ・「世界遺産とは」のセクション         → id="about"
  ・「登録遺産」のセクション             → id="list"
  ・「世界遺産登録数の比較」のセクション → id="comparison"

ナビゲーションのリンクは、それぞれ href="#about"、href="#list"、
href="#comparison" として、上記のidへ飛ぶように実装してください。

--------------------------------------------------------------------
【要件4】外部リンクについて
--------------------------------------------------------------------
各遺産の紹介には「UNESCOのページへ」というリンクテキストで、
原稿.txtに記載されたUNESCO公式サイトのURLへリンクしてください。

  ・姫路城         → https://whc.unesco.org/en/list/661
  ・白川郷の合掌造り集落 → https://whc.unesco.org/en/list/734
  ・厳島神社       → https://whc.unesco.org/en/list/776

外部サイトへのリンクになるため、新しいタブで開くようにしてください。
（target属性がどのような役割を持つか、調べた上で実装してみましょう）

--------------------------------------------------------------------
【要件5】画像
--------------------------------------------------------------------
imagesフォルダ内の画像を、対応するセクション・遺産の位置にそれぞれ
配置してください。各<img>タグには、以下のalt属性をそのまま指定して
ください。

  ・about.webp        → alt="屋久島の豊かな渓流の風景"
  ・himejijyo.webp    → alt="白漆喰の外壁が美しい姫路城の天守"
  ・shirakawagou.webp → alt="茅葺き屋根の合掌造り家屋が並ぶ白川郷の集落"
  ・itsukushima.webp  → alt="海に浮かぶ朱色の大鳥居がある厳島神社"

--------------------------------------------------------------------
【要件6】テキスト・数値について
--------------------------------------------------------------------
見出しや本文、表内の数値はすべて原稿.txtの内容をそのまま使用して
ください（文言の改変は不要です）。

--------------------------------------------------------------------
【提出前チェックリスト】
--------------------------------------------------------------------
□ header / nav / main / section / footer を適切に使い分けたか
□ h1〜h3の見出しレベルに抜け・飛び級（例：h1の次にh3）がないか
□ 3つの大セクションに指定通りのid（about / list / comparison）を
   付けたか、ナビゲーションからその場所へ正しくジャンプできるか
□ すべての画像にalt属性を入れたか
□ 表がthead/tbody/th/tdを使って正しくマークアップされているか
□ UNESCOへの外部リンクが新しいタブで開くようになっているか
□ ブラウザで実際に表示し、リンク・画像・表が正しく表示されるか確認したか
