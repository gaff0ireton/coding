01

GET / 単一オブジェクト

1件のデータを取得してConsoleに表示する

JSONPlaceholderの /posts には、架空の投稿データが100件用意されています。 各投稿には userId、id、title、body が入っています。 URLを /posts/1 とすると、その中からIDが1の投稿を1件だけ取得できるため、 最初はこのURLを使って「APIから1つのオブジェクトを取得して中身を確認する」練習をします。

コピーするコード

// APIから投稿データを1件取得する関数
async function getPost() {
  try {
    // fetch()でAPIへアクセスし、レスポンスを受け取る
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/posts/1"
    );

    // 通信結果が正常でなければエラーを発生させる
    if (!response.ok) {
      throw new Error("データの取得に失敗しました");
    }

    // 受け取ったJSONをJavaScriptのオブジェクトに変換する
    const post = await response.json();

    // 取得したオブジェクトをConsoleに表示する
    console.log(post);
  } catch (error) {
    // エラーが発生した場合はConsoleに表示する
    console.error(error);
  }
}

// 関数を実行する
getPost();

やってみよう

コードを practice.js に貼り付けてページを再読み込みし、 Consoleに userId、id、title、body を持つオブジェクトが表示されるか確認します。

try...catch で例外処理を行う

API通信では、ネットワークの問題やURLの間違いなどによって、 データを正しく取得できないことがあります。 そのため、この教材では最初から try...catch を使って、 エラーが起きた場合の処理も書いています。

try

エラーが起きる可能性のある処理を書く

→
catch

エラーが発生したときの処理を書く

try の中でエラーが発生すると、その時点で残りの処理は中断され、 catch に処理が移ります。

throw new Error() とは

throw は、自分でエラーを発生させるための書き方です。 今回は response.ok が false の場合に、 通信が正常ではなかったと判断してエラーを発生させています。

throw new Error("データの取得に失敗しました");

new Error() でエラーを表すオブジェクトを作り、 throw でそのエラーを発生させます。 発生したエラーは catch が受け取ります。

Error オブジェクトとは

Error オブジェクトは、エラーの内容を表すためのオブジェクトです。 new Error("メッセージ") のように作成すると、 エラーについての情報を持つオブジェクトが作られます。

エラーを作る new Error("取得に失敗しました")
→
catchの引数で受け取る catch (error)
→
内容を確認する error.message

catch (error) の error は、catch が受け取る引数です。 今回のコードでは、throw new Error(...) で発生させた Error オブジェクトが、この引数 error に渡されます。 そのため、catchの中では引数 error を使ってエラーの内容を調べられます。 console.error(error) ならErrorオブジェクト全体を確認でき、 error.message なら、そのオブジェクトが持つメッセージを取得できます。

例：/posts/5

次に console.log(post.title) に変えて、タイトルだけを表示してください。

02

Array / Object / map()

複数データを取得して必要な形にまとめる

JSONPlaceholderの /users には、架空のユーザーデータが10件用意されています。 各ユーザーには id、name、username、email、 address、phone、website、company などの情報が入っています。 今回はまず /users をそのまま取得してConsoleで中身を確認し、 どんなプロパティがあるのかを見たうえで、map() を使って必要な情報だけを持つ新しい配列に整理します。

コピーするコード

// APIからユーザー一覧を取得する関数
async function getUsers() {
  try {
    // fetch()でユーザー一覧を取得する
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );

    // 通信結果が正常でなければエラーを発生させる
    if (!response.ok) {
      throw new Error("ユーザーの取得に失敗しました");
    }

    // 受け取ったJSONをJavaScriptの配列に変換する
    const users = await response.json();

    // まず取得したデータをそのままConsoleで確認する
    console.log(users);
    console.table(users);

    // 中身を確認したうえで、必要なデータだけを持つ新しい配列を作る
    const userList = users.map((user) => {
      return {
        id: user.id,
        name: user.name,
        email: user.email,
        city: user.address.city,
      };
    });

    // map()で整理したあとの配列も確認する
    console.log(userList);
    console.table(userList);
  } catch (error) {
    // エラーが発生した場合はConsoleに表示する
    console.error(error);
  }
}

// 関数を実行する
getUsers();

console.table() とは

console.table() は、配列やオブジェクトの内容を Console上にテーブル形式で表示するためのメソッドです。

console.log() でもデータを確認できますが、 複数のオブジェクトが入った配列を確認するときは、 console.table() を使うと、各プロパティが列ごとに整理されるため見やすくなります。

通常の確認 console.log(users);
→
表形式で確認 console.table(users);

今回は、APIから取得した直後の users を console.log(users) と console.table(users) の両方で表示します。 まず取得したデータを確認して、「どんなプロパティがあるのか」「どの値を使えそうか」を調べるのが目的です。 そのあと map() で整理した userList も同じ2つの方法で表示し、 整理する前と後でデータがどう変わったかを比較します。

map() とは

map() は、配列の中にある各要素を順番に取り出して処理し、 その結果から新しい配列を作るためのメソッドです。

map() の引数には、各要素に対して実行したい関数を渡します。 今回は users.map((user) => { ... }) と書いているため、 map() の引数としてアロー関数を渡しています。 さらに、そのアロー関数の引数 user には、 users 配列の要素が1件ずつ順番に渡されます。

つまり、1回目の処理では1人目のユーザーが引数 user に入り、 2回目では2人目のユーザーが入る、という流れです。 今回は、先にConsoleで users の中身を確認し、 id、name、email、address などのプロパティがあることを確認してから、 引数 user を使って id、name、email、 address.city だけを取り出し、新しい配列 userList を作っています。

APIから取得した配列 users
→
各要素が引数userに渡される users.map((user) => ...)
→
新しい配列 userList

map() は元の users 配列を書き換えるのではなく、 加工した結果を別の新しい配列として作ります。 「APIから取得する → Consoleで中身を確認する → 使う値を決める → map() で使いやすい形に整える」 という順で考えると、初めて見るAPIでも処理を組み立てやすくなります。

配列 users
→
各要素 user
→
入れ子の値 user.address.city

改造課題

city の代わりに phone や website を取得してみてください。

慣れたら、company の中にある name も追加してみましょう。

user.company.name

03

Array / find() / DOM

IDを指定して1人を探し、HTMLを書き換える

02で確認した /users には10人分のユーザー情報が配列で入っています。 今回は、その中から id が3のユーザーを find() で1人だけ探します。 見つかったユーザーには名前、メールアドレス、住所、会社情報などが入っているため、 その値を使って、あらかじめHTMLに用意してあるプロフィールのテキストを書き換えてみましょう。

コピーするコード

// APIからユーザー一覧を取得し、指定したIDのユーザーを表示する関数
async function showUser() {
  // 書き換えるHTML要素を取得する
  const userName = document.querySelector("#user-name");
  const userEmail = document.querySelector("#user-email");
  const userCity = document.querySelector("#user-city");
  const userCompany = document.querySelector("#user-company");

  try {
    // fetch()でユーザー一覧を取得する
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );

    // 通信結果が正常でなければエラーを発生させる
    if (!response.ok) {
      throw new Error("ユーザーの取得に失敗しました");
    }

    // 受け取ったJSONをJavaScriptの配列に変換する
    const users = await response.json();

    // find()を使って、idが3のユーザーを1人だけ探す
    const user = users.find((user) => {
      return user.id === 3;
    });

    // 指定したユーザーが見つからなければエラーを発生させる
    if (!user) {
      throw new Error("指定したユーザーが見つかりません");
    }

    // 見つけたユーザーをConsoleで確認する
    console.log(user);

    // 取得した値を使ってHTMLのテキストを書き換える
    userName.textContent = user.name;
    userEmail.textContent = user.email;
    userCity.textContent = user.address.city;
    userCompany.textContent = user.company.name;
  } catch (error) {
    // エラーが発生した場合はConsoleに表示する
    console.error(error);
  }
}

// 関数を実行する
showUser();

find() とは

find() は、配列の中から条件に合う要素を探し、 最初に見つかった1件を返すメソッドです。

find() の引数にも、条件を確認するための関数を渡します。 今回は users.find((user) => { ... }) と書いているため、 find() の引数としてアロー関数を渡しています。 そのアロー関数の引数 user には、 users 配列の要素が1件ずつ順番に渡されます。

受け取った引数 user に対して user.id === 3 を確認し、 条件が true になった最初のユーザーを返します。 今回は id === 3 のユーザーを探しています。 IDは1人のユーザーを特定するための値なので、1件を取り出す find() が適しています。

find() 1件を探す オブジェクトを返す
filter() 条件に合うものをすべて残す 配列を返す

filter() でもIDが3のユーザーだけを残すことはできますが、 結果は1件だけでも配列になります。 今回のように「1人を探して、その人の情報を使う」場合は find() のほうが扱いやすくなります。

04

Array / filter() / DOM

条件に合うデータだけを残してHTMLに表示する

JSONPlaceholderの /todos へアクセスすると、 「やること」を表すToDoデータをまとめて取得できます。 それぞれのデータには userId、id、title、 completed というプロパティがあり、 completed には完了済みなら true、 未完了なら false が入っています。

今回はこのデータを使って、filter() で 「完了済みのToDoだけ」を取り出し、 その件数と内容の一部をHTMLへ表示してみましょう。

コピーするコード

// APIからToDo一覧を取得し、完了済みだけを画面に表示する関数
async function showCompletedTodos() {
  // 件数を表示するHTML要素を取得する
  const todoCount = document.querySelector("#todo-count");

  // ToDo一覧を表示するHTML要素を取得する
  const todoList = document.querySelector("#todo-list");

  try {
    // fetch()でToDo一覧を取得する
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/todos"
    );

    // 通信結果が正常でなければエラーを発生させる
    if (!response.ok) {
      throw new Error("ToDoの取得に失敗しました");
    }

    // 受け取ったJSONをJavaScriptの配列に変換する
    const todos = await response.json();

    // まず取得したデータをConsoleで確認する
    console.log(todos);
    console.table(todos);

    // filter()を使って、completedがtrueのデータだけを残す
    const completedTodos = todos.filter((todo) => {
      return todo.completed === true;
    });

    // 完了済みToDoの件数をHTMLに表示する
    todoCount.textContent = `${completedTodos.length}件`;

    // 表示前に一覧エリアを空にする
    todoList.innerHTML = "";

    // 最初の5件をHTMLへ表示する
    completedTodos.slice(0, 5).forEach((todo) => {
      todoList.insertAdjacentHTML(
        "beforeend",
        `<li>${todo.title}</li>`
      );
    });
  } catch (error) {
    // エラーが発生した場合はConsoleに表示する
    console.error(error);

    // HTMLにもエラーメッセージを表示する
    todoCount.textContent = "取得失敗";
    todoList.innerHTML = `<li>${error.message}</li>`;
  }
}

// 関数を実行する
showCompletedTodos();

filter() の引数は何をしているのか

filter() の引数には、条件を確認するための関数を渡します。 今回は todos.filter((todo) => { ... }) と書いているため、 filter() の引数としてアロー関数を渡しています。 そのアロー関数の引数 todo には、 todos 配列の要素が1件ずつ順番に渡されます。

受け取った引数 todo に対して todo.completed === true を確認し、 条件が true になった要素だけを残します。 find() が条件に合う最初の1件を返すのに対し、 filter() は条件に合うすべての要素を集めて、新しい配列を作ります。

取得直後

200件 todos
filter()

条件で絞り込み

完了済みだけ completedTodos

slice() とは

slice() は、配列の中から指定した範囲だけを取り出して、 新しい配列を作るメソッドです。

今回は completedTodos.slice(0, 5) と書いているため、 完了済みToDoの配列 completedTodos の中から、 先頭から5件だけを取り出しています。

元の配列 completedTodos
→
0番目から5番目の手前まで slice(0, 5)
→
最初の5件 新しい配列

slice(開始位置, 終了位置) のように指定し、 終了位置の要素は含まれません。 そのため slice(0, 5) は、 インデックス0〜4までの5件を取り出します。 また、slice() は元の配列 completedTodos を変更しません。

05

Fetch API → DOM

取得したデータをWebページに表示する

01でも使った /posts には、userId、id、title、 body を持つ投稿データが100件入っています。 今回は /posts として投稿をまとめて取得し、最初の6件だけを slice() で取り出します。 その6件を forEach() で順番に処理し、タイトルや本文をHTMLのカードとして画面に追加してみましょう。

コピーするコード

// APIから投稿一覧を取得して画面に表示する関数
async function showPosts() {
  // 投稿を表示するHTML要素を取得する
  const postList = document.querySelector("#post-list");

  try {
    // fetch()で投稿一覧を取得する
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/posts"
    );

    // 通信結果が正常でなければエラーを発生させる
    if (!response.ok) {
      throw new Error("投稿の取得に失敗しました");
    }

    // 受け取ったJSONをJavaScriptの配列に変換する
    const posts = await response.json();

    // 最初の6件だけを新しい配列として取り出す
    const displayPosts = posts.slice(0, 6);

    // もともと表示されている内容を空にする
    postList.innerHTML = "";

    // 各投稿データを順番にHTMLとして追加する
    displayPosts.forEach((post) => {
      postList.insertAdjacentHTML(
        "beforeend",
        `<article class="post-card">
          <p class="post-id">POST ${post.id}</p>
          <h3>${post.title}</h3>
          <p>${post.body}</p>
        </article>`
      );
    });
  } catch (error) {
    // エラーが発生した場合は画面にメッセージを表示する
    postList.innerHTML =
      `<p class="error-message">${error.message}</p>`;
  }
}

// 関数を実行する
showPosts();

/users と /posts の2つのAPIを取得してください。 今回はIDが 5 のユーザーを対象にします。

/users から find() で id === 5 のユーザーを探し、 名前・メールアドレス・会社名をそれぞれ指定された要素へ textContent で表示してください。

次に /posts から filter() で userId === 5 の投稿をすべて取り出し、 投稿件数を表示したあと、#practice-profile-posts へ insertAdjacentHTML() で投稿を追加してください。

01：3人のユーザー情報を表示する 
// ユーザー情報を取得して表示する関数
async function showUsers() {
  try {
    // ユーザー一覧を取得する
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );

    if (!response.ok) {
      throw new Error("ユーザーの取得に失敗しました");
    }

    // JSONをJavaScriptの配列に変換する
    const users = await response.json();

    // 取得したデータを確認する
    console.table(users);

    // 最初の3人だけを取り出して順番に処理する
    users.slice(0, 3).forEach((user, index) => {
      // indexは0から始まるので、HTMLの番号に合わせて+1する
      const number = index + 1;

      // 各ユーザーの情報をHTMLに表示する
      document.querySelector(
        `#practice-user-${number}-name`
      ).textContent = user.name;

      document.querySelector(
        `#practice-user-${number}-email`
      ).textContent = user.email;

      document.querySelector(
        `#practice-user-${number}-city`
      ).textContent = user.address.city;
    });
  } catch (error) {
    console.error(error);
  }
}

// 関数を実行する
showUsers();
02：未完了ToDoを抽出して表示する 
// 未完了ToDoを取得して表示する関数
async function showTodos() {
  // 件数の表示先を取得する
  const todoCount = document.querySelector(
    "#practice-todo-count"
  );

  try {
    // ToDo一覧を取得する
    const response = await fetch(
      "https://jsonplaceholder.typicode.com/todos"
    );

    if (!response.ok) {
      throw new Error("ToDoの取得に失敗しました");
    }

    // JSONをJavaScriptの配列に変換する
    const todos = await response.json();

    // userIdが3、かつ未完了のToDoだけを抽出する
    const filteredTodos = todos.filter((todo) => {
      return todo.userId === 3 && todo.completed === false;
    });

    // 抽出したデータを確認する
    console.table(filteredTodos);

    // 該当件数を表示する
    todoCount.textContent = `${filteredTodos.length}件`;

    // 抽出結果の先頭3件を順番に表示する
    filteredTodos.slice(0, 3).forEach((todo, index) => {
      const number = index + 1;

      document.querySelector(
        `#practice-todo-${number}`
      ).textContent = todo.title;
    });
  } catch (error) {
    console.error(error);
  }
}

// 関数を実行する
showTodos();

04：ユーザー情報と投稿をまとめて表示する 
// ユーザー情報と投稿をまとめて表示する関数
async function showUserAndPosts() {
  // ユーザー情報の表示先を取得する
  const userName = document.querySelector(
    "#practice-profile-name"
  );

  const userEmail = document.querySelector(
    "#practice-profile-email"
  );

  const userCompany = document.querySelector(
    "#practice-profile-company"
  );

  const postCount = document.querySelector(
    "#practice-profile-post-count"
  );

  // 投稿の追加先を取得する
  const postList = document.querySelector(
    "#practice-profile-posts"
  );

  try {
    // /usersからユーザー一覧を取得する
    const usersResponse = await fetch(
      "https://jsonplaceholder.typicode.com/users"
    );

    if (!usersResponse.ok) {
      throw new Error("ユーザーの取得に失敗しました");
    }

    const users = await usersResponse.json();

    // idが5のユーザーを1人探す
    const user = users.find((user) => {
      return user.id === 5;
    });

    if (!user) {
      throw new Error("ユーザーが見つかりません");
    }

    // /postsから投稿一覧を取得する
    const postsResponse = await fetch(
      "https://jsonplaceholder.typicode.com/posts"
    );

    if (!postsResponse.ok) {
      throw new Error("投稿の取得に失敗しました");
    }

    const posts = await postsResponse.json();

    // userIdが5の投稿だけを抽出する
    const userPosts = posts.filter((post) => {
      return post.userId === 5;
    });

    // 取得結果を確認する
    console.log(user);
    console.table(userPosts);

    // ユーザー情報をHTMLに表示する
    userName.textContent = user.name;
    userEmail.textContent = user.email;
    userCompany.textContent = user.company.name;

    // 投稿件数を表示する
    postCount.textContent = `${userPosts.length}件`;

    // 最初から入っている説明文を削除する
    postList.innerHTML = "";

    // 投稿を指定されたHTML構造で追加する
    userPosts.forEach((post) => {
      postList.insertAdjacentHTML(
        "beforeend",
        `
          <article class="practice-post-item">
            <h4>${post.title}</h4>
            <p>${post.body}</p>
          </article>
        `
      );
    });
  } catch (error) {
    console.error(error);
  }
}

// 関数を実行する
showUserAndPosts();
