# HTML5 Level.1 第4章 レスポンシブWebデザイン ハンズオン教材

`HTML5教科書.pdf`の第4章（PDF 211〜239ページ、問題4-1〜4-27）を、HTML・CSS・少量のJavaScriptを読みながら体系的に学ぶ教材です。

## 開き方

1. このフォルダでローカルサーバーを起動します。
2. `index.html`をブラウザーで開きます。
3. ブラウザー幅を375px、768px、1200px付近へ変更し、配置と画像候補を比較します。

例：

```bash
python3 -m http.server 8080
```

その後、`http://localhost:8080/`を開いてください。`srcset`の候補確認やモーダル動作を安定して試すため、`file://`ではなくローカルサーバーを推奨します。

## 学習順

1. レスポンシブの全体像
2. viewport
3. フルードグリッド／フルードイメージ
4. メディアクエリ
5. 高解像度画像・srcset・picture・CSSスプライト
6. script・電話リンク・アイコン・スタンドアロン表示

各セクション末に、A〜Eの5選択肢による模擬問題があります。フルードグリッドとフルードイメージは個別に確認できるよう、SECTION 03のみ2問です。単一選択はラジオボタン、複数選択はチェックボックスです。回答後はモーダルで判定し、正解時は理由、不正解時はヒントを表示します。
